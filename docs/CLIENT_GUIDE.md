# TrinTech-Guardian — Client Guide

**What it does in plain language**

Guardian watches for hostile network activity (port scans, brute-force patterns, suspicious local processes) and can temporarily block offending sources. It also plants lightweight decoy services to detect scanners early.

**What you will receive**

1. A signed Rules of Engagement defining scope and mode (dry-run vs live)
2. Monitoring during the agreed window
3. A client report (HTML, PDF when available) with timeline and recommendations
4. Optional continuous monitoring as a managed service

**What it will not do**

- Scan systems outside the agreed scope
- Make permanent irreversible changes without approval
- Share findings outside the NDA

**Your responsibilities**

- Provide accurate asset list and contacts
- Approve dry-run vs live mode in writing
- Request releases of blocked addresses if a false positive occurs
